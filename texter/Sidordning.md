# Page order

All pages on the site, in the order they are shown. The indentation follows the folders in `texter/`: a page is listed under the page whose folder it lies in. The build takes the order of the top menu, the "You are here" line and the list "Pages in …" from this file, and warns if the file and the folders do not match.

The start page Sustainable Society and the other top pages lie side by side in `texter/`, but count as subpages of the start page.
